# Data provenance & licensing notice

This project (the `web/`, `tools/`, and `packages/` directories) is a small,
educational, **non-commercial** web game inspired by Ragnarok Online. It is
built for a private group of friends.

## Game data (numbers/balance) comes from Hercules

The JSON files under `packages/data-gen/` are generated by the extractor in
`tools/data-extract/` from the **Hercules** server-emulator databases that live
in this repository under `db/re/` and `npc/re/` (the surrounding Hercules tree).

Hercules is licensed under the **GNU General Public License v3** (see `LICENSE`
at the repository root). The extracted JSON is therefore a derivative work of
GPLv3-licensed data. Accordingly:

- The **new code** in `web/`, `tools/`, and `packages/` is licensed under
  **GPL-3.0-or-later** to remain compatible.
- If this project is ever published, its source must be made available under
  GPLv3, or the repository should remain private.
- See `packages/data-gen/ATTRIBUTION.md` for the per-file attribution that is
  emitted alongside the generated data.

## No Gravity / RO client art is included or shipped

This repository contains **no** Ragnarok Online sprites, maps, sounds, or other
client art (those are copyrighted by Gravity Co., Ltd. and are not part of
Hercules). All in-game visuals use placeholder / freely-licensed art
